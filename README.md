# Project Overview
The dashboard tracks sales performance from 2023 to June 2025, focusing on revenue, products, customer orders, order status, coupon usage, and referral sources.

# Key Metrics
- Total Revenue: 1,264,761.96
- Total Records: 1,200
- Average Revenue: 1,053.97
- Median Revenue: 823.62

# Dashboard Features
- Revenue by product category
- Yearly revenue trend
- Order status analysis
- Coupon usage analysis
- Referral source analysis
- Interactive slicers for Coupons and Referral Source

# Key Insights
- Chairs generated the highest revenue at 195,620.11.
- Phones generated the lowest revenue at 151,722.39.
- Cancelled orders were the most common order status.
- Coupons were used in 891 out of 1,200 transactions.
- Instagram was the leading referral source.
- Revenue data for 2025 covers January to June only.
